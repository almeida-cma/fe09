Enunciados das Landing Pages Reais

Desenvolva páginas profissionais para 5 segmentos de mercado utilizando a Biblioteca de 52 Componentes e Modelos em Grid.

📋 Como Trabalhar em Qualquer Desafio

Siga este fluxo passo a passo para construir sua página de forma modular e organizada:

  1. Abra a ferramenta Biblioteca Web & Modelos em Grid no seu navegador.
  2. Crie um arquivo index.html limpo no seu editor de código (VSCode, OneCompiler, etc.).
  3. Navegue pelas abas da biblioteca e copie o HTML, CSS e JS dos componentes solicitados no enunciado.
  4. Cole os blocos no seu arquivo, unifique o estilo na tag <style> e os scripts em <script>.
  5. Aplique a paleta de cores recomendada substituindo os tons roxos padrões da biblioteca.
  6. Regra de Ouro: Teste nas larguras 320px, 375px e Desktop. A página não pode ter barra de rolagem horizontal indesejada!
