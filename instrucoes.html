📋 Instruções — Projeto Aurora

Você recebeu o arquivo projeto.html com 5 bugs. Este caderno explica o que deveria acontecer em cada um, o que acontece hoje, o que o console mostra e como consertar.

📂 Como trabalhar

  1. Abra o projeto.html no navegador (duplo clique).
  2. Pressione F12 para abrir as ferramentas e vá na aba Console. É lá que os erros aparecem.
  3. Abra o projeto.html também no VSCode (ou seu editor de código preferido).
  4. Leia o Bug 1 abaixo. Faça a ação indicada no navegador e veja o erro aparecer no console.
  5. Encontre a linha correspondente no código, conserte, salve o arquivo e recarregue a página (F5).
  6. Confirme que o bug 1 sumiu e passe para o próximo.
  7. No final, faça o upload do seu arquivo no validador abaixo para confirmar os 5 consertos.

Botão de orçamento não faz nada

O que deveria acontecer Clicar no botão amarelo "Solicitar orçamento" abre uma janela de aviso com o texto: "Obrigado pelo interesse! Entraremos em contato em breve."
O que acontece hoje Clicar no botão não faz nada na tela e gera um erro em vermelho no console.
No console (F12) ao clicar: Uncaught ReferenceError: pedirOrcamento is not defined at HTMLButtonElement.onclick (projeto.html:XX)
Onde olhar No projeto.html, procure a tag <button> do hero. O atributo onclick está configurado chamando pedirOrcamento(). Porém, a função declarada no <script> foi criada com o nome solicitarOrcamento().
Como consertar Troque o nome chamado no onclick do botão para corresponder ao nome real da função:
<button id="btn-orcamento" class="btn-hero" onclick="solicitarOrcamento()">Solicitar orçamento</button>

Campo de nome não cumprimenta

O que deveria acontecer Ao digitar o seu nome no campo "Seu nome" e teclar Enter (ou clicar fora do campo), o sistema exibe o alerta: "Olá, [seu nome]! Seja bem-vindo(a)."
O que acontece hoje Após digitar o nome e teclar Enter, nada é exibido e o console acusa que tentamos ler uma propriedade de null.
No console (F12) ao confirmar o nome: Uncaught TypeError: Cannot read properties of null (reading 'value') at personalizarSaudacao (projeto.html:XX)
Onde olhar No <script>, dentro da função personalizarSaudacao, o código busca por document.getElementById("nome-completo"). Porém, no HTML, o campo foi definido com id="nome". Como o ID procurado não existe, o método retorna null e a linha seguinte quebra ao tentar acessar .value.
Como consertar Substitua "nome-completo" pelo ID correto "nome" dentro de getElementById:
let campo = document.getElementById("nome");

Card de preço não reage ao mouse

O que deveria acontecer Passar o cursor do mouse sobre o card "Essencial" muda o fundo para amarelo claro e a borda para laranja. Ao retirar o mouse de cima dele, o card volta ao estado padrão (fundo branco, borda cinza).
O que acontece hoje Passar o mouse sobre o card não faz nada. O card só muda de cor se você clicar nele, e depois ele fica preso na cor amarela para sempre.
No console: (silencioso — nada aparece, pois a sintaxe está correta, mas o evento utilizado foi o errado)
Onde olhar No <script>, procure por addEventListener("click", entrarNoCard). O evento configurado foi "click" em vez de "mouseover". Além disso, a função sairDoCard já existe no arquivo, mas falta registrá-la para o evento "mouseout".
Como consertar Substitua o evento "click" por "mouseover" e adicione uma nova linha registrando "mouseout":
document.getElementById("card-preco").addEventListener("mouseover", entrarNoCard); document.getElementById("card-preco").addEventListener("mouseout", sairDoCard);

Cálculo de desconto não mostra resultado

O que deveria acontecer Ao clicar em "Calcular desconto", o valor com 10% de desconto aplicado deve aparecer na tela (ex.: "Com desconto: R$ 1350.00").
O que acontece hoje Ao clicar no botão, nenhum resultado aparece e o console acusa erro ao tentar chamar .toFixed() em algo indefinido (undefined).
No console (F12) ao clicar: Uncaught TypeError: Cannot read properties of undefined (reading 'toFixed') at calcularEExibir (projeto.html:XX)
Onde olhar A função calcularDesconto(preco) faz a conta, mas não possui a palavra-chave return. Em JavaScript, uma função sem return devolve undefined. Por isso, a função seguinte tenta fazer resultado.toFixed(2) em cima de nada e quebra.
Como consertar Retorne o resultado final inserindo return precoFinal; antes de fechar a função:
function calcularDesconto(preco) { const taxa = 0.1; let desconto = preco * taxa; let precoFinal = preco - desconto; return precoFinal; }

Contador de caracteres fica sempre zerado

O que deveria acontecer Conforme você digita na caixa "Mensagem", o contador abaixo deve atualizar em tempo real, informando o número exato de caracteres inseridos (ex.: "15 / 200").
O que acontece hoje Ao digitar na mensagem, o contador fica travado em "0 / 200". O console mostra que o número esperado era maior do que zero.
No console, ao digitar: Contador: 0 caracteres (esperado: 12)
Onde olhar Na função contarCaracteres(texto), repare no laço de repetição: for (let i = 0; i < 0; i++). A variável i começa valendo 0. Como a condição de continuação é i < 0 (0 é menor que 0? Não!), ela já começa falsa e o laço nunca chega a rodar. A variável total permanece em 0.
Como consertar Faça o laço percorrer toda a extensão da string trocando i < 0 por i < texto.length:
for (let i = 0; i < texto.length; i++) {
