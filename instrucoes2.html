🔍 Desafio de Depuração — Livraria Lumina

O portal da Livraria Lumina foi entregue com 5 problemas no JavaScript. Agora é a sua vez de identificar e solucionar cada um deles usando o console do navegador.

🎯 Seu Plano de Investigação

  1. Abra o projeto2.html no navegador e pressione F12 para acessar a aba Console.
  2. Abra o mesmo arquivo no VSCode (ou seu editor de código).
  3. Reproduza os problemas descritos abaixo para ver as mensagens de erro reais no console.
  4. Investigue a causa consultando o código do <script> e aplique a correção.
  5. Quando concluir, carregue o arquivo no final desta página para validar se os 5 bugs foram solucionados!

Botão do catálogo não responde

Comportamento Esperado: Ao clicar no botão amarelo "Baixar catálogo", deve abrir um alerta avisando que o catálogo foi enviado para o e-mail.
O que acontece hoje: Ao clicar, nada acontece na tela e o console acusa que uma função não foi definida.
Erro no Console (F12): Uncaught ReferenceError: baixarCatalogo is not defined at HTMLButtonElement.onclick
Pista de Investigação: Compare cuidadosamente o nome da função que a tag <button> está tentando chamar no seu onclick com o nome da função que foi realmente declarada no bloco <script>.

Campo de identificação quebra ao confirmar nome

Comportamento Esperado: Ao digitar seu nome no campo "Seu Nome" e teclar Enter (ou clicar fora), o site deve saudar o leitor com uma mensagem personalizada contendo o nome digitado.
O que acontece hoje: Ao teclar Enter no campo, nenhuma mensagem é exibida e o console acusa que o código tentou ler value de algo que é null.
Erro no Console (F12): Uncaught TypeError: Cannot read properties of null (reading 'value') at saudarLeitor
Pista de Investigação: Na função saudarLeitor(), observe o argumento passado para o document.getElementById(). O ID procurado pelo JavaScript bate de verdade com o atributo id="" que está na tag <input> do formulário?

Card de assinatura não reage ao passar o mouse

Comportamento Esperado: Ao passar o cursor do mouse sobre o card "Assinatura Lumina", o fundo deve mudar para amarelo claro. Ao retirar o mouse de cima dele, o card deve restaurar seu fundo branco original.
O que acontece hoje: Passar o mouse sobre o card não faz nada. O card só muda de cor se for clicado, e depois disso nunca mais volta para a cor branca original.
Erro no Console (F12): (Silencioso — nenhum erro aparece no console, pois o código é válido, mas os eventos configurados não condizem com a experiência de hover)
Pista de Investigação: Observe a linha onde o addEventListener é registrado para o card. Qual evento do mouse é disparado ao passar o cursor por cima? E qual evento é necessário registrar para detectar quando o cursor se afasta do elemento?

Cálculo de cupom quebra na formatação

Comportamento Esperado: Ao clicar em "Aplicar 15% de Desconto", o valor com desconto deve aparecer formatado com duas casas decimais (ex: "Total com desconto: R$ 85.00").
O que acontece hoje: Nenhum texto de resultado aparece na tela e o console acusa erro ao tentar invocar toFixed em um valor indefinido.
Erro no Console (F12): Uncaught TypeError: Cannot read properties of undefined (reading 'toFixed') at calcularCupom
Pista de Investigação: A função aplicarCupomDesconto(valor) realiza a operação matemática corretamente, mas o que ela devolve para a função que a chamou? Lembre-se da instrução fundamental que entrega o resultado de uma função em JavaScript.

Contador de resenha não sai do zero

Comportamento Esperado: Conforme o leitor escreve na caixa de resenha, o contador logo abaixo deve acompanhar a quantidade de caracteres digitados em tempo real (ex.: "24 / 150").
O que acontece hoje: Mesmo digitando dezenas de palavras, o contador permanece estagnado em "0 / 150".
Mensagem no Console ao digitar: Contador da resenha: 0 (esperado: 24)
Pista de Investigação: Analise o laço for dentro de contarCaracteresResenha(). Qual é a condição estipulada para o laço continuar executando? Como podemos fazer essa condição depender do tamanho real do texto recebido?
